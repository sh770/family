# לוח אירועים משפחתי

אתר אינטרנט להצגת אירועים משפחתיים קרובים, ימי הולדת וימי נישואין, לפי תאריכים עבריים ולועזיים.

🌐 **כתובת האתר:** https://sh770.github.io/family/

## תכונות

- הצגת ימי הולדת וימי נישואין של בני המשפחה.
- הצגת שם פרטי ושם משפחה, לצד שמות ההורים.
- הצגת תאריכים עבריים ולועזיים.
- הצגת השנה העברית בפורמט כגון `ה'תשמ"א`.
- ספירה לאחור עד לאירוע הקרוב.
- סינון לפי טווח זמן, סוג אירוע ומשפחה.
- מצב תצוגה בהיר ומצב כהה, עם שמירת הבחירה בדפדפן.
- התראות דפדפן מקומיות כאשר האתר פתוח.
- בחירת סוג האירועים, מספר הימים מראש ושעת ההתראה.
- שמירת כל העדפות ההתראות במכשיר באמצעות LocalStorage.
- מניעת שליחה כפולה של אותה תזכורת באותו מכשיר.

## הערה חשובה לגבי התראות

ההתראות פועלות מקומית בדפדפן בלבד, ללא שרת התראות, ללא Web Push וללא שירות חיצוני.

- האתר חייב להיות פתוח באחת מלשוניות הדפדפן כדי לבדוק את מועדי התזכורות.
- אפשר לבחור אילו אירועים להזכיר, כמה ימים מראש ובאיזו שעה.
- ההעדפות ומזהי ההתראות שכבר נשלחו נשמרים ב-LocalStorage במכשיר של המשתמש.
- אם סוגרים את האתר לחלוטין, לא תישלח התראה בזמן שהאתר סגור.
- קובץ `sw.js` משמש להצגת התראות מקומיות בדפדפנים התומכים בכך בלבד; הוא אינו מאזין להודעות Push ואינו פונה לשרת.

## טכנולוגיות

- HTML
- CSS
- JavaScript
- ממשק בעברית ובכיווניות מימין לשמאל (RTL)

האתר עצמו סטטי ואינו דורש התקנת ספריות חיצוניות.

## מבנה המאגר

```text
family/
├── index.html
├── sw.js
├── README.md
└── .github/
    └── workflows/
        └── pages.yml
```

- `index.html` – קובץ האתר הראשי, הכולל את המבנה, העיצוב והקוד.
- `sw.js` – שירות עובד מקומי להצגת התראות דפדפן בלבד, ללא קבלת הודעות Push.
- `README.md` – מסמך זה.
- `.github/workflows/pages.yml` – תהליך אוטומטי לפרסום האתר באמצעות GitHub Pages.

## פרסום ועדכון

האתר מתפרסם באמצעות GitHub Pages. כל שינוי שנשמר בענף `main` מפעיל את תהליך הפרסום האוטומטי.

כתובת האתר: https://sh770.github.io/family/

## עדכון התוכן

עורכים את הקובץ `index.html` ושומרים את השינויים בענף `main`. הפרסום מתבצע אוטומטית באמצעות GitHub Actions.
