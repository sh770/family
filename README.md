# לוח אירועים משפחתי

אתר אינטרנט להצגת אירועים משפחתיים קרובים, ימי הולדת וימי נישואין, לפי תאריכים עבריים ולועזיים.

🌐 **כתובת האתר:** https://sh770.github.io/family/

## תכונות

- הצגת ימי הולדת וימי נישואין של בני המשפחה.
- הצגת שם פרטי ושם משפחה, לצד שמות ההורים.
- הצגת תאריכים עבריים ולועזיים.
- הצגת השנה העברית בפורמט כגון `ה'תשמ"א`.
- ספירה לאחור עד לאירוע הקרוב.
- סינון לפי טווח זמן, סוג אירוע ומשפחה.
- מצב תצוגה בהיר ומצב כהה, עם שמירת הבחירה בדפדפן.
- אפשרות לבקש הרשאה להצגת התראות דפדפן ולבחור את מועד התזכורת.

## הערה חשובה לגבי התראות

בגרסה הנוכחית ההתראות נבדקות כאשר האתר פתוח בדפדפן. הרשאת התראות לבדה אינה מאפשרת לאתר סטטי שנמצא ב-GitHub Pages לתזמן ולשלוח התראות כשהאתר סגור.

כדי לקבל התראות גם כשהאתר סגור צריך להוסיף שירות Push בצד השרת, Service Worker, ושמירה מאובטחת של הרשמות המשתמשים. רכיב זה עדיין אינו מוגדר בגרסה הנוכחית.

## טכנולוגיות

- HTML
- CSS
- JavaScript
- ממשק בעברית ובכיווניות מימין לשמאל (RTL)

האתר עצמו סטטי ואינו דורש התקנת ספריות חיצוניות.

## מבנה המאגר

```text
family/
├── index.html
├── README.md
└── .github/
    └── workflows/
        └── pages.yml
```

- `index.html` – קובץ האתר הראשי, הכולל את המבנה, העיצוב והקוד.
- `README.md` – מסמך זה.
- `.github/workflows/pages.yml` – תהליך אוטומטי לפרסום האתר באמצעות GitHub Pages.

## פרסום ועדכון

האתר מתפרסם באמצעות GitHub Pages. כל שינוי שנשמר בענף `main` מפעיל את תהליך הפרסום האוטומטי.

כתובת האתר: https://sh770.github.io/family/

## עדכון התוכן

עורכים את הקובץ `index.html` ושומרים את השינויים בענף `main`. הפרסום מתבצע אוטומטית באמצעות GitHub Actions.

## רישיון

המאגר נועד לשימוש אישי ומשפחתי.
