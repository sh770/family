# לוח אירועים משפחתי

אתר אינטרנט פשוט ונוח להצגת אירועים משפחתיים קרובים, כגון ימי הולדת וימי נישואין.

🌐 **כתובת האתר:** https://sh770.github.io/family/

## מה אפשר למצוא באתר?

- הצגת ימי הולדת וימי נישואין של בני המשפחה.
- הצגת תאריכים עבריים ולועזיים.
- ספירה לאחור עד לאירוע הקרוב.
- סינון וצפייה באירועים לפי האפשרויות המוצגות באתר.
- אפשרות להפעיל התראות דפדפן ולבחור תזכורת ביום האירוע, יום לפני, 3 ימים לפני או שבוע לפני.
- התאמה למסכים שונים, כולל טלפונים ניידים ומחשבים.
- ממשק בעברית ובכיווניות מימין לשמאל (RTL).

**הערה לגבי התראות:** ההתראות מבוססות על הרשאת הדפדפן ופועלות כאשר האתר פתוח בדפדפן. אם סוגרים את האתר לחלוטין, לא תישלח תזכורת ברקע.

## טכנולוגיות

האתר נבנה באמצעות טכנולוגיות Web בסיסיות:

- HTML
- CSS
- JavaScript

אין צורך בשרת, במסד נתונים או בהתקנת ספריות חיצוניות. האתר פועל ישירות בדפדפן.

## מבנה המאגר

```text
family/
├── index.html
├── README.md
└── .github/
    └── workflows/
        └── pages.yml
```

- `index.html` – קובץ האתר הראשי, הכולל את המבנה, העיצוב והקוד להפעלת האתר.
- `README.md` – מסמך זה.
- `.github/workflows/pages.yml` – תהליך אוטומטי לפרסום האתר באמצעות GitHub Pages.

## פרסום ועדכון האתר

האתר מתפרסם באמצעות **GitHub Pages**.

לאחר הגדרת GitHub Pages במאגר, תהליך GitHub Actions שבקובץ `.github/workflows/pages.yml` מפרסם את תוכן המאגר בכל דחיפה (push) לענף `main). ניתן גם להפעיל את התהליך ידנית מתוך לשונית **Actions**.

כתובת האתר:
https://sh770.github.io/family/

## עדכון התוכן

כדי לעדכן את פרטי האירועים או את קוד האתר, עורכים את הקובץ `index.html` ושומרים את השינויים בענף `main`. תהליך הפרסום האוטומטי יופעל בעקבות העדכון.

## רישיון

המאגר נועד לשימוש אישי ומשפחתי.
